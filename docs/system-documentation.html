System Documentation

School Management System for Computer Science, Computer Engineering and Entrepreneurship: enrollment, grades, appointment tickets and tuition, with an Admin who oversees everything.

1. OverviewWhat the system does

Students sign up and wait for Admin approval. After that they enroll in classes, see their grades, and book appointment tickets for the registrar or accounting. Each person only sees the tools for their role.

👑 Admin

Approves or denies accounts, enrollments and tickets. Can edit or delete almost anything.

📋 Registrar

Manages courses, class sections and enrollment requests. Handles registration and inquiry tickets.

💰 Accounting

Verifies reference numbers, receives cash and updates tuition ledgers.

🧑‍🏫 Faculty

Sees own classes and rosters, and enters grades.

🎓 Student

Requests classes, views grades and balance, books appointments.

2. System architectureHow the pieces connect

The browser talks to one Express API. The API checks the login token and the role, then reads or writes PostgreSQL. In development the Vite server forwards /api requests to the API on port 5000.

3. Database schemaTables and relationships

Nine tables. Every person is a row in users. A profile table adds the details for their role. The status columns (pending, approved, denied) power the Admin's approve and deny buttons.

What each table is for

TablePurpose
usersLogin accounts for everyone. status controls approval, is_active lets the Admin deactivate an account.
student_profiles / staff_profiles / faculty_profilesExtra details for each role. Deleting a user deletes the profile too (ON DELETE CASCADE).
coursesThe catalog. Every course belongs to one of the three programs.
class_sectionsA course offered with a teacher, room, schedule and seat limit. First-year courses have two sections.
enrollmentsA student's request for a section. Unique per student and section. Holds the grade.
payment_ticketsAppointment bookings with a unique reference number, shown at the window.
tuition_ledgersOne running balance per student. Created when the student is approved.

Start everything

# 1. Open Docker Desktop, then in the project folder:
docker compose up -d

# 2. Create the tables and the demo data (this wipes old data)
Get-Content database\schema.sql | docker compose exec -T db psql -U sms_user -d sms_db
cd server
node seed.js

# 3. Start the API
npm run dev

# 4. In another terminal, start the website
cd client
npm install lucide-react
npm run dev
